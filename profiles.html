プロファイル配布

Matt Winton Style とは

Matt Winton Style は、「High Energy, Short Time（高エネルギー・短時間）」を基本コンセプトとした焙煎アプローチです。 短時間で高いエネルギーを豆に投入し、明るい酸味・クリーンな甘み・フローラルな香りを最大限に引き出すことを目指します。 ここで配布するプロファイルは、世界バリスタチャンピオン Matt Winton 氏のスタイルを参考に、 ROEST Sample Roaster 向けに最適化したものです。

🔥

高い投入温度

通常 205〜210℃ で投入。豆の芯まで素早く熱を伝え、中盤以降のエネルギー不足を防ぐ。TP（中点）を高く・早く通過させるのが特徴。

📉

滑らかな RoR 管理

1ハゼに向かって火力を段階的に絞り、RoR（温度上昇率）がなだらかに右肩下がりになるよう調整。「Baked（停滞による風味の欠如）」を防ぐ。

⏱️

短いデベロップメント

1ハゼ開始から煎り止めまでを 30〜45 秒程度に収める。DTR（デベロップメントタイム比）は全体の 8〜15% が目安。

☕

豆の特性に合わせた調整

高地産・硬い豆（エチオピア、ケニア等）は高い投入温度と強い初期火力。低地産・柔らかい豆（ブラジル等）は投入温度を数度下げて丁寧に管理。

インポート方法

  1. 上の「全プロファイル一括ダウンロード」ボタン、または下の個別ダウンロードリンクをタップして JSON ファイルを保存します。
  2. 珈琲豆焙煎くんを起動し、「設定」画面を開きます。
  3. 「データ管理」→「プロファイルをインポート」をタップします。
  4. 先ほど保存した JSON ファイルを選択するとインポートが完了します。

※ インポートは既存プロファイルへの追加として処理されます。重複する名前のプロファイルは上書きされる場合があります。インポート前に既存データをエクスポートしてバックアップすることをおすすめします。

ご利用にあたって

  • 本プロファイルは ROEST / Sample Roaster を基準に設計されています。他の焙煎機をお使いの場合は、投入温度・ドロップ温度などを適宜調整してください。
  • 豆の産地・収穫年・保管状態によって最適な数値は異なります。プロファイルはあくまで出発点としてお使いください。
  • 配布するプロファイルは目標値のみを含んでいます（カスタムアラートは含まれていません）。必要に応じてアプリ内で追加してください。
  • 本プロファイルの利用・再配布は自由です。ご自身の焙煎スタイルに合わせてカスタマイズしてお使いください。
